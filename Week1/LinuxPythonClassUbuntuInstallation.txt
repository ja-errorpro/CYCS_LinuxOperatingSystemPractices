Q : How do I change the IP of my Ubuntu 22.04 to a fixed IP (192.168.0.57)?

Copilot :

To set a static IP address like 192.168.0.57 in Ubuntu 22.04, you’ll typically use Netplan, which is the default network configuration tool. Here’s how to do it step by step:

🛠️ Step-by-Step: Set Static IP with Netplan

1. Find Your Network Interface Name

Run:

bash
ip link

Look for something like enp0s3, ens33, or eth0.    # enp0s3

2. Edit Netplan Configuration

Open the Netplan config file:

bash
sudo cp /etc/netplan/01-network-manager-all.yaml /etc/netplan/01-network-manager-all.yaml-original
sudo nano /etc/netplan/01-network-manager-all.yaml

3. Modify the File to Use Static IP

# YAML files are sensitive to indentation — use spaces, not tabs.

Here’s an example configuration:

yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    enp0s3:  # Replace with your actual interface name
      dhcp4: no
      addresses:
        - 192.168.0.57/24
      gateway4: 192.168.0.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1

4. Apply the Configuration

Save and exit (Ctrl+O, Enter, Ctrl+X), then run:

bash
sudo netplan apply

✅ Verify the Change

bash
ip a

or

bash
ip route

Q : How do I install an ssh server on my Ubuntu-2204?

Copilot :

To install an SSH server on Ubuntu 22.04, you’ll want to install OpenSSH Server, which is the most widely used SSH implementation. Here’s how to do it:

🛠️ Step-by-Step: Install OpenSSH Server

1. Update Package Lists

bash
sudo apt update

2. Install OpenSSH Server

bash
sudo apt install openssh-server

This installs the SSH daemon (sshd) and starts it automatically.

✅ Check SSH Service Status

bash
sudo systemctl status ssh

You should see something like:

Active: active (running)

If it’s not running, start it manually:

bash
sudo systemctl start ssh

And enable it to start on boot:

bash
sudo systemctl enable ssh

Find Your IP Address

To connect to your Ubuntu machine via SSH, you’ll need its IP:

bash
ip a

Look for an address like 192.168.x.x under your network interface.

🔐 Test SSH Access

From another machine (Linux/macOS/WSL) in the same local area network (LAN), run:

bash
ssh <User>@192.168.0.57     

Replace <User> with your Ubuntu user and 192.168.0.57 with your IP.

# 192.168.x.x is a LAN-IP ; 
# to make WAN (wide area network) connections, needs to set up the router (i.e., ssh to the router-IP,
# and the router "forwards" packets to (e.g.) 192.168.0.57 when it sees port 22 ; see below)

🧱 Firewall Consideration (Optional)

If you’re using ufw (Uncomplicated Firewall), allow SSH:

bash
sudo ufw allow ssh
sudo ufw enable

Q : How do I change the port that my ssh-server listens to on Ubuntu-2204?

Copilot :

To change the port your SSH server listens on in Ubuntu 22.04, you’ll need to modify the SSH configuration file and restart the service. Here's how to do it safely:

🛠️ Step-by-Step: Change SSH Port

1. Choose a New Port

Pick a port number between 1024–65535 (e.g., 2222) to avoid conflicts with reserved ports.

2. Edit the SSH Configuration File

Open the SSH daemon config:

bash
sudo nano /etc/ssh/sshd_config

Find the line:

bash
#Port 22

Add a line beneath it:

bash
Port 2222

Save and exit (Ctrl+o, ENTER, Ctrl+x).

3. Allow the new port in the Firewall (if enabled)

If you're using ufw:

bash
sudo ufw allow 2222/tcp

You can also remove the old rule:

bash
sudo ufw delete allow ssh

4. Restart the SSH Service

bash
sudo systemctl restart ssh

# hsia : below also should work
#   > sudo service sshd stop
#   > sudo service sshd start

✅ Test the new port

From another machine:

bash
ssh -p 2222 <User>@ip_addr   # if LAN, then ip_addr is 192.168.x.x else ip_addr is ip of the router

🧠 Bonus Tip

If you’re using VirtualBox and you are using NAT (instead of '橋接介面卡' or 'bridged interface'), make sure the port is forwarded (by VirtualBox?) :

Go to VM Settings → Network → Advanced → Port Forwarding

Add a rule:
  Host Port: 2222
  Guest Port: 2222
  Protocol: TCP

--------------------------------------------------------

To connect to this VM from the outside (e.g., 'cmd' of Windows) via ssh :

  > ssh -p 2222 <User>@ip_addr

You can also connect to this VM by using FileZilla via sftp.
(Use an 'sftp' connection with the port number being '2222'.)

Q : How do I check whether ufw is enabled on my Ubuntu-2204?

Copilot :

To check whether ufw (Uncomplicated Firewall) is enabled on Ubuntu 22.04, you can use the following command:

🔍 Check UFW Status

bash
sudo ufw status

If UFW is enabled, you’ll see something like:

Status: active
To                         Action      From
--                         ------      ----
22/tcp                     ALLOW       Anywhere

If it’s disabled, you’ll see:

Status: inactive

🧠 Bonus: Check UFW Service Status

To see if the UFW service is running at the system level:

bash
sudo systemctl status ufw

🚀 Enable UFW (if needed)

If it’s inactive and you want to enable it:

# ＦＩＲＳＴ (if you don’t want to lock yourself out)

bash
sudo ufw allow ssh

# ＴＨＥＮ (remember! only AFTER you have done the above)

bash
sudo ufw enable
